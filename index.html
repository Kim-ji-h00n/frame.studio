로그인 / 회원가입

회색 “사진” 칸은 다른 사람이 자기 사진을 넣는 자리예요. 내 사진·스티커·문구로 프레임을 꾸며 보세요.

선택한 요소:

요소를 끌어서 옮기고, 선택하면 나오는 ✕로 삭제, ⤡를 끌어서 크기·회전을 조절해요. Delete 키로 삭제, Ctrl+Z로 되돌리기. 사진 파일을 화면으로 끌어다 놓아도 추가돼요. 빈 곳을 누르면 선택이 해제돼요.

선택한 사진:

사진 위의 ✕를 누르면 바로 빠지고, 빈 칸을 누르거나 파일을 끌어다 놓으면 새 사진이 들어가요. 사진을 눌러 선택하면 끌어서 위치를, 버튼으로 크기를 맞출 수 있어요.
